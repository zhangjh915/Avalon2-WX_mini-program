## 已定的决策

1. **透明通道**：全部走「近黑底生成 + 程序抠图」，不做深色圆底。
   实测抠出来的 PNG 在白 / 羊皮纸 / 正义绿 / 邪恶红 / 页面底五种底色上都成立。方法见手册 5.5。
2. **不分皮肤**：图标长在 UI 框架里，而 UI 配色固定，不随身份牌皮肤变。
3. **长桌走九宫格**：长宽比有 30 种（1.19–2.89 连续），按配置各画一张不现实。见手册 5.6。
4. **桌心纹章独立成层**，不烤进桌面图——否则会随桌子比例浮动、极端比例被裁掉。
