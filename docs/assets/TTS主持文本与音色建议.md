### 首夜流程句

这些句子由角色候选池动态组合。未知角色变体下，即使角色被秘密移除，候选角色名仍会被朗读，避免通过主持词泄露。

| 编号 | 文本模板 | 音色与风格 |
|---|---|---|
| ceremony_close_eyes | 夜幕降临。请所有骑士闭上眼睛，将手机扣在桌面上。不要交谈，也不要触碰其他玩家。 | 低沉中性旁白，庄重、克制，语速偏慢；句间留明确停顿。 |
| ceremony_mutual_evil | {角色列表}，请睁开眼睛。安静地确认与你共享黑暗的同伴。 | 神秘低沉男声，角色名清晰；结尾保留五秒静音。 |
| ceremony_evil_close | 黑暗中的共谋者，请闭上眼睛。记住你看到的面孔，收起所有表情。 | 低沉男声，神秘但不过度表演；结尾留两秒。 |
| ceremony_hidden | {角色列表}保持闭眼。所有单向身份关系已经通过命运密令传递；不要举手，不要发出声音。 | 冷静女声，强调“保持闭眼”和“不要举手”。 |
| ceremony_lancelot | 正义的兰斯洛特与邪恶的兰斯洛特，请同时睁开眼睛，确认彼此。五、四、三、二、一。请闭上眼睛。 | 低沉中性旁白，倒数稳定，前后各留两秒。 |
| ceremony_dawn | 命运已经完成低语。天色渐明，诸位骑士，请睁开眼睛。第一场远征即将开始。 | 史诗感女声，由轻到明亮，最后一句坚定。 |

动态角色列表不适合预合成成一条固定音频。建议分别合成每个角色名短音频，运行时按候选池拼接；第一版也可以先只合成开头、结尾和兰斯洛特固定句，中间由房主照屏幕朗读。
