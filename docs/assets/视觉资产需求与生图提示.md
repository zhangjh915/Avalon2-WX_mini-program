# 《圆桌秘闻》视觉资产需求与生图提示

## 总体美术方向

关键词：

- 中世纪圆桌
- 羊皮纸档案
- 暗金、深木、烛火
- 克制的史诗感
- 不要过度游戏 UI，不要二次元，不要太魔幻网游
- 像一套“王国档案馆 + 桌游主持台”

建议画幅：

- 小程序首页/阶段背景：`9:16`
- 卡牌/角色图：`3:4`
- 图标素材：`1:1`，最好透明背景
- 桌面背景：`16:9` 或 `4:3`，可裁切

## 角色头像后续批量生成

先不必每个角色都生成完整人物图。第一版更建议做：

- 正义方通用骑士头像 3-5 张
- 邪恶方通用阴谋家头像 3-5 张
- 特殊角色再补：
  - 亚瑟
  - 教士
  - 摩根勒菲
  - 盲眼杀手
  - 公爵
  - 侍从

角色图统一风格：

```text
中世纪桌游角色卡插画，半身像，羊皮纸背景，暗金边框，克制史诗风，清晰面部轮廓，不要现代服装，不要夸张网游盔甲，不要二次元，适合微信小程序身份卡，竖版 3:4
```

## UI 使用建议

- 首页用整张背景图，按钮浮在下方。
- 房间选座页用桌面俯视图作为核心视觉。
- 游戏中默认不常驻大座位表，只显示当前阶段卡片。
- 需要选人时展开桌面图，让玩家点座位。
- 结算页用羊皮纸战报底图。
