# 抽卡记录：任务牌背面

配置：每版提示词 × 2 个模型 × 3 张独立抽卡（非组图，独立采样）。
尺寸统一 `1728x2304`（3:4），`watermark: false`。

模型：
- `5` = `doubao-seedream-5-0-260128`
- `5pro` = `doubao-seedream-5-0-pro-260628`

> **接口差异**：`5pro` 不支持 `sequential_image_generation` 参数，
> 连传 `"disabled"` 都会报 `InvalidParameter`。非组图时必须整个字段省略。
> 这也意味着**成套组图模式在 pro 上不可用**，成套资产要么用 5.0，要么靠提示词约束逐张生成。

## v1

**提示词**（与最初文档一致，未做任何针对性约束）：

```
中世纪任务卡牌背面，深墨绿底色，中央一枚金色圣杯纹章，四周细金线边框与低饱和藤蔓浮雕，
对称构图，神秘克制。暗金、深木、烛火色调，克制的史诗感，不要二次元，不要网游特效，
不要文字，不要水印，画面干净
```

**结果**

| 文件 | 评价 |
|---|---|
| `cardback-v1_5_1` | ✗ 生成成"一张卡的照片"，四角是白色，贴进深色界面会有白角 |
| `cardback-v1_5_2` | ✓ 全出血，圣杯中等大小，藤蔓精细，可用 |
| `cardback-v1_5_3` | △ 全出血但圣杯太小，缩到 52px 会完全消失 |
| `cardback-v1_5pro_1` | ✗ 自作主张加了木质相框、桌面和蜡烛，是环境照片不是卡面 |
| `cardback-v1_5pro_2` | ✓✓ 全出血，金杯带宝石，皮革压纹质感，很好 |
| `cardback-v1_5pro_3` | ✓✓ 全出血，圣杯最大最清晰，橡叶橡果边框，质感最好 |

**结论**

1. **pro 的材质与细节明显更好**，但也更容易"过度发挥"——擅自加相框、桌面、蜡烛这类环境元素。
2. **主体尺寸是最要命的问题**。任务牌在界面上只有 `104x154rpx`（约 52×77px），
   `5_3` 那种小圣杯缩下去会完全看不见。必须显式要求主体占画面高度的比例。
3. 两个模型都有概率生成"卡片实物照片"而不是"平面卡面"：5.0 表现为白色圆角外框，
   pro 表现为相框+环境。必须在提示词里显式禁止。

→ v2 针对这三点加约束。

## v2

**在 v1 基础上新增三条约束**：平面卡面铺满出血、主体占画面三分之二以上、显式禁止相框与环境。

```
中世纪桌游任务卡牌的正面平视卡面设计图。深墨绿皮革压纹底色铺满整个画面，四边完全出血。
画面正中一只华丽的金色圣杯，圣杯高度占画面高度三分之二以上，轮廓厚重清晰，金属质感明确，
即使缩小到很小也能一眼认出。四周环绕低饱和金色藤蔓与叶片浮雕，四角有对称卷草纹，
最外一道细金线边框。暗金、深木、烛火色调，克制的史诗感。严禁出现：白色边框、白色四角、
圆角外框、相框、画框、桌面、蜡烛、手、任何环境或背景物体、卡片投影、文字、水印。
不要二次元，不要网游特效
```

**结果**：6 张**全部**消除了白角与相框，主体也都放大了，约束完全生效。

但把图缩到界面真实尺寸（52×77px）后发现新问题：**金色藤蔓背景与主体抢视线**。
5.0 的三张尤其明显——藤蔓和圣杯同为高亮金色，缩小后糊成一团金色噪点。
pro 的三张因为背景略暗而好一些，其中 `5pro_1` 最清楚。

→ v3 转向"背景压暗、主体提亮"。

## 结论

**模型选 `doubao-seedream-5-0-pro-260628`。** 材质、金属质感和细节明显强于 5.0；
代价是更容易自作主张加环境元素，但 v2/v3 的禁止清单已经能稳定压住。

**提示词用 v3。** 决定性证据是缩到界面真实尺寸后的对比：v2 的金色藤蔓背景在
52×77px 下会和主体糊成一片，v3 的"背景压暗、主体提亮"直接解决了这个问题。

**推荐候选：`cardback-v3_5pro_1` 与 `cardback-v3_5pro_3`**，两张在真实尺寸下都一眼可辨，
区别只是后者更华丽（杯身带宝石）。

## 重要修正：不能拿任务牌的尺寸去套所有资产

初版结论错在把「52×77px」当成了所有资产的标准。实际查了代码，各资产显示尺寸差很多：

| 资产 | 代码 | 实际显示 | 该用什么风格 |
|---|---|---|---|
| **身份牌整卡** `.role-card` | `100%` × ≥`720rpx` | **≈375 × 360+ px** | **可以很华丽**，细节看得见 |
| 身份牌内插画位 `.role-art-placeholder` | `168 × 212rpx` | 84 × 106 px | 中等，主体要清楚 |
| **任务牌** `.mission-result-card` | `104 × 154rpx` | **52 × 77 px** | 必须极简，只靠明暗对比 |
| 仪式符号 `.ceremony-symbol` | `132 × 132rpx` | 66 × 66 px | 接近剪影 |
| 顶部图标 `.table-icon-button` | `58 × 58rpx` | 29 × 29 px | 纯剪影，无细节 |

身份牌比任务牌大将近 7 倍。**所以 v3 的「背景压暗」只是任务牌的结论，不适用于身份牌**——
身份牌是玩家会盯着看几十秒的主视觉，v2 那种华丽藤蔓质感在那个尺寸下是加分项。

对照图见 `generated/_size-compare.png`：同样两张图，在身份牌尺度差异明显，
缩到任务牌尺寸后几乎分辨不出。

**给后续所有资产的通用经验**

1. **必须按界面真实尺寸验收**。全尺寸好看不代表能用——本项目卡牌只有 52×77px，
   放大图上精致的藤蔓在实际尺寸下就是噪点。
2. 提示词里要显式写**主体占画面比例**，否则模型倾向于把主体画小、把装饰画满。
3. 必须显式禁止：白边、白色四角、圆角外框、相框、桌面、蜡烛、手、投影。
   这些是两个模型共同的"过度发挥"倾向，且 pro 更严重。
4. **背景永远压暗，只让主体亮**。这是小尺寸可辨认性的关键，比任何细节都重要。
5. 抽卡有波动：v3 的 `5pro_2` 又出现了白边。**每组都要多抽几张再挑**，不能只生成一张。
