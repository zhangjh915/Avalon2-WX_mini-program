# 《圆桌秘闻》文档索引

只负责身份分配、投票查验、以及这些信息的留存与随时查看。

## 代码与脚本

| 路径 | 说明 |
|---|---|
| `miniprogram/` | 小程序端 |
| `cloudfunctions/avalonGame/` | 云函数与服务端规则引擎 |
| `tests/` | 单元、集成与端到端测试 |
| `scripts/run-tests.sh` | 跑全部单元与集成测试 |
| `scripts/run-e2e.sh` | 在模拟器里跑完整一局并截图 |

本机没有安装系统 Node，两个脚本都会自动回退到微信开发者工具内置的 node（v16）。
